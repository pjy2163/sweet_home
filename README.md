# 스위트홈(SweetHome)

<img width="900" alt="sweethome-portfolio-cover-text-large" src="https://github.com/user-attachments/assets/2b04aef8-4142-4f75-bbf1-7a614d42dcab" />


스위트홈은 집을 추천하는 서비스가 아니라, 사용자가 여러 후보지를 비교할 때 객관적인 데이터를 기반으로 의사결정을 내릴 수 있도록 돕는 서비스입니다.

## 프로젝트 비전

사용자가 원하는 질문은 단순합니다.

> 어디가 더 좋은가?

하지만 부동산 의사결정에 필요한 정보는 여러 서비스와 공공데이터에 흩어져 있습니다.

- 호갱노노
- 네이버 부동산
- 부동산지인
- 카카오맵
- 국토교통부 실거래가
- 경찰청 범죄 통계
- KOSIS
- 서울 열린데이터광장

스위트홈은 흩어진 데이터를 지역 단위로 통합하고, 후보지 간 차이를 비교 가능한 형태로 보여주는 AI 기반 부동산 비교 분석 플랫폼을 지향합니다.

## 서비스 정의

사용자가 집을 구할 때 다음 요소를 종합적으로 비교하여 의사결정을 돕습니다.

- 가격
- 교통
- 상권
- 범죄
- 인구
- 생활인프라
- 미래가치

초기 MVP의 타겟은 서울에서 월세 또는 전세를 구하는 사회초년생, 1인가구, 독립 예정자입니다.

MVP의 핵심 질문은 다음 하나입니다.

> A와 B 중 내 생활 조건에 더 적합한 곳은 어디이며, 그 이유는 무엇인가?

최종 결정은 사용자가 합니다.

## 핵심 가치

집을 추천하는 것이 아니라, 집을 비교하여 데이터 기반 의사결정을 돕습니다.

장기적으로는 "어디가 더 좋은가?"가 아니라 "나에게 무엇이 더 적합한가?"를 데이터로 설명하는 서비스를 목표로 합니다.

## 데이터 출처와 산출 기준

MVP는 서울 행정동을 공통 단위로 사용하며, 원천별 기준 시점과 공간 단위가 다르다는 점을 결과와 함께 표시합니다. 지도 API는 지표별 원천명, 공식 URL, 이용 조건, 기준일, 산출 방식, 제공·결측 행정동 수를 metadata로 반환합니다.

| 분석 영역 | 공식 원천 | MVP 산출 방식 |
| --- | --- | --- |
| 주거 비용 | 서울 전월세 실거래 공공데이터 | 법정동 실거래를 행정동에 연결하고 같은 기준월의 서울 평균과 비교 |
| 거주·활동 특성 | 서울 열린데이터광장 `행정동 단위 서울 생활인구(내국인)` | 시간대별 체류 추정인구를 24시간·주간·야간 평균으로 분리 |
| 야간 생활환경 | [서울시 안심귀갓길 서비스](https://data.seoul.go.kr/dataList/OA-21697/S/1/datasetView.do), 서울시 유흥·단란주점 인허가 정보 | 시설 좌표를 행정동 경계에 공간조인해 참고 근거로 제공 |
| 생활 편의 | 서울시 상권분석서비스 `점포-행정동` | 행정동별 점포 수를 면적 1㎢ 기준으로 환산 |
| 교통 접근성 | [T-DATA 지하철역 좌표정보](https://t-data.seoul.go.kr/dataprovide/trafficdataviewfile.do?data_id=36), [서울시 버스정류소 위치정보](https://data.seoul.go.kr/dataList/OA-15067/S/1/datasetView.do) | 공식 위치 좌표를 [SGIS 행정동 경계](https://sgis.kostat.go.kr/view/pss/openDataIntrcn)에 공간조인 |

버스정류소 원천은 2026-07-01 기준 공공누리 제1유형 자료입니다. 서울 433개 행정동 중 현재 경계가 연결된 420개 지역에 정류소 수와 면적당 밀도를 제공하며, 나머지 13개 지역은 정류소가 0개인 것으로 처리하지 않고 `데이터 없음`으로 구분합니다.

생활인구는 주민등록상 거주인구가 아닌 체류 추정치입니다. 야간 생활환경 지표는 범죄율이나 지역의 안전도를 의미하지 않으며, 교통 지표는 정적 위치 근거로서 실제 도보시간·배차·환승 편의·출퇴근 시간을 반영하지 않습니다. 스위트홈은 이 지표들을 투자 판단, 지역 순위 또는 안전 보장에 사용하지 않습니다.
