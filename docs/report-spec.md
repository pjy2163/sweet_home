# MVP Report Spec

이 문서는 SweetHome 첫 번째 MVP 리포트의 입력, 출력, 해석 기준을 정의합니다.

첫 번째 MVP는 서울 전월세 실거래 데이터를 기반으로 후보 행정동 2개의 가격 수준을 서울 평균과 비교합니다.

## Goal

사용자가 후보 지역 2개를 입력하면 다음 질문에 답합니다.

> 이 지역의 전월세 가격은 같은 달 서울 평균 대비 어느 정도 수준인가?

리포트는 매물 추천, 투자 판단, 특정 지역 우열 판단을 하지 않습니다.
제공하는 정보는 가격 비교를 위한 참고 지표입니다.

## Data Source

리포트는 다음 데이터 마트를 사용합니다.

```text
data/processed/real_estate_price_comparison.csv
```

이 데이터 마트는 `real_estate_fact.csv`를 기반으로 생성합니다.

```text
raw real estate data
→ real_estate_fact
→ real_estate_price_comparison
→ report
```

## Input

CLI 입력은 다음 형태입니다.

```bash
.venv/bin/python src/report/generate_report.py --a 개포1동 --b 개포2동
```

구 이름까지 지정해야 하는 경우 다음처럼 입력합니다.

```bash
.venv/bin/python src/report/generate_report.py --a "강남구 개포1동" --b "강남구 개포2동"
```

특정 계약월을 지정할 수 있습니다.

```bash
.venv/bin/python src/report/generate_report.py --a 개포1동 --b 개포2동 --month 2025-12
```

| 인자 | 필수 여부 | 설명 |
| --- | --- | --- |
| `--a` | 필수 | 첫 번째 후보 행정동 |
| `--b` | 필수 | 두 번째 후보 행정동 |
| `--month` | 선택 | 비교 기준월. 없으면 두 지역의 공통 최신 월 사용 |

## Region Resolution

사용자는 행정동명으로 입력하지만, 내부 조회는 `region_id` 기준으로 수행합니다.

처리 규칙:

- `개포1동`처럼 행정동명만 입력하면 행정동명으로 조회합니다.
- `강남구 개포1동`처럼 구와 행정동명을 함께 입력하면 둘 다 일치하는 지역을 조회합니다.
- 같은 행정동명이 여러 구에 있으면 구 이름을 함께 입력하도록 오류를 반환합니다.
- 존재하지 않는 지역이면 오류를 반환합니다.

이 규칙은 사용자 입력은 쉽게 유지하면서도 내부 데이터 조회는 안정적인 키로 처리하기 위한 것입니다.

## Month Resolution

기준월 처리 규칙:

- 사용자가 `--month`를 지정하면 해당 월을 사용합니다.
- `--month`가 없으면 두 후보 지역이 모두 가진 최신 공통 월을 사용합니다.
- 지정한 월의 데이터가 한 지역에 없으면 오류를 반환합니다.

월은 `YYYY-MM` 형식을 사용합니다.

## Output Sections

리포트는 다음 섹션으로 구성합니다.

1. 리포트 제목
2. 기준월
3. 서울 평균 보증금
4. 서울 평균 전세가
5. 후보 지역 A 가격 지표
6. 후보 지역 B 가격 지표
7. 해석 문장
8. 추천/투자 조언이 아니라는 안내
9. 데이터 기준과 한계

## Metrics

| 지표 | 설명 |
| --- | --- |
| 평균 보증금 | 전월세 전체 거래의 평균 보증금 |
| 서울 평균 보증금 | 같은 월 서울 전체 평균 보증금 |
| 서울 평균 보증금 대비 | 지역 평균 보증금이 서울 평균보다 높은/낮은 비율 |
| 평균 전세가 | 전세 거래의 평균 보증금 |
| 서울 평균 전세가 | 같은 월 서울 전체 평균 전세 보증금 |
| 서울 평균 전세가 대비 | 지역 평균 전세가가 서울 평균보다 높은/낮은 비율 |
| 거래량 | 행정동 매핑 가중치를 적용한 거래 건수 |
| 거래량 해석 주의 | 거래량이 낮아 평균 가격의 대표성이 약할 수 있음을 표시 |

## Interpretation Rules

가격 수준 문구는 서울 평균 대비율을 기준으로 생성합니다.

| 조건 | 문구 |
| --- | --- |
| `+10%` 이상 | 서울 평균보다 높은 편입니다 |
| `-10%` 이하 | 서울 평균보다 낮은 편입니다 |
| `-10%` 초과, `+10%` 미만 | 서울 평균과 비슷한 범위입니다 |
| 데이터 없음 | 서울 평균과 비교하기 어렵습니다 |

후보 지역 간 전세가 차이는 다음 기준을 사용합니다.

| 조건 | 문구 |
| --- | --- |
| 차이 `5%p` 이상 | 더 높은 지역과 차이를 표시 |
| 차이 `5%p` 미만 | 큰 차이가 아니라고 표시 |

거래량이 낮은 지역이 하나라도 있으면 다음 문장을 추가합니다.

```text
거래량이 적은 지역이 있어 가격 수준을 단정적으로 해석하지 않습니다.
```

## Boundaries

리포트는 다음 표현을 사용하지 않습니다.

- 이 지역을 선택하세요
- 이 지역이 더 좋습니다
- 투자 가치가 높습니다
- 가격이 오를 것입니다

리포트는 다음 표현을 사용합니다.

- 서울 평균보다 높은 편입니다
- 서울 평균과 비슷한 범위입니다
- 거래량이 적어 해석에 주의가 필요합니다
- 후보 지역 비교를 위한 참고 정보입니다

## Example Output

```text
[SweetHome 가격 비교 리포트]

기준월: 2025-12
서울 평균 보증금: 25,430만원
서울 평균 전세가: 44,824만원

강남구 개포1동
- 평균 보증금: 52,535만원
- 서울 평균 보증금 대비: +106.6%
- 평균 전세가: 70,487만원
- 서울 평균 전세가 대비: +57.2%
- 거래량: 63.2건

강남구 개포2동
- 평균 보증금: 53,016만원
- 서울 평균 보증금 대비: +108.5%
- 평균 전세가: 72,416만원
- 서울 평균 전세가 대비: +61.6%
- 거래량: 102.8건

해석:
- 개포1동의 전세가는 서울 평균보다 높은 편입니다.
- 개포2동의 전세가는 서울 평균보다 높은 편입니다.
- 두 지역의 전세가 수준은 서울 평균 대비 큰 차이가 아닙니다.
- 이 리포트는 투자 추천이 아니라 후보 지역 비교를 위한 참고 정보입니다.

데이터 기준:
- 원천: 서울 전월세 실거래 데이터 기반
- 집계: 행정동/계약월 기준 집계
- 한계: 법정동-행정동 매핑과 거래량에 따라 지역 대표성이 달라질 수 있습니다.
```

## Future Extensions

가격 비교 MVP 이후 다음 지표를 추가할 수 있습니다.

- 생활인구
- 안전 대체 지표
- 상권/생활 편의 지표
- 교통 접근성 지표

추가 지표도 같은 원칙을 따릅니다.

- 행정동 기준으로 정규화합니다.
- 기준일 또는 기준월을 명시합니다.
- 데이터 출처와 한계를 표시합니다.
- 추천이 아니라 비교 근거로 표현합니다.
