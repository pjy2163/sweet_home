# Data Dictionary

## region_master

모든 데이터의 기준 지역 테이블입니다.

| 컬럼명 | 설명 |
| --- | --- |
| region_id | 서비스 내부 지역 ID. 초기에는 `행정동코드`와 동일 |
| 시도명 | 시/도 이름 |
| 시군구명 | 시/군/구 이름 |
| 행정동코드 | 행정동 코드 |
| 행정동명 | 행정동 이름 |

## dong_mapping

법정동과 행정동을 연결하는 매핑 테이블입니다.

| 컬럼명 | 설명 |
| --- | --- |
| 행정동코드 | 행정동 코드 |
| 행정동명 | 행정동 이름 |
| 법정동코드 | 법정동 코드 |
| 법정동명 | 법정동 이름 |
| 시도명 | 시/도 이름 |
| 시군구명 | 시/군/구 이름 |
| 개정일자 | 코드 개정일자 |
| 연결번호 | 법정동 연계정보의 연결번호 |
